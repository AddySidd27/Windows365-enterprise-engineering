# Security and Privacy

Do not commit credentials, access tokens, certificates, private keys, real tenant identifiers, user information, or unsanitized screenshots.

Use placeholders such as:

- `<TENANT_ID>`
- `<SUBSCRIPTION_ID>`
- `<RESOURCE_GROUP>`
- `user@contoso.com`
- `CPC-PILOT-01`

Before publishing, run the repository validation script and manually inspect every image.
