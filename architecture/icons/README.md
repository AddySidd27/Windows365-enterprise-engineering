# Microsoft Azure Architecture Icons

The SVG files in this folder come from the official Microsoft Azure Architecture Icons pack.

They are used only in architecture diagrams and documentation. The icons are not modified, cropped, flipped, or used to represent a non-Microsoft product.

Source: [Azure Architecture Icons](https://learn.microsoft.com/azure/architecture/icons/)

Microsoft permits these icons for architecture diagrams, training material, and documentation under the terms shown on the source page.
